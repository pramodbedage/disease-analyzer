# Disease Analyzer & Health Companion

A comprehensive AI-powered health assistant designed to help users identify potential medical conditions, find doctors, and understand symptoms.

## 🚀 Features

*   **Disease Information**: Detailed database of 200+ diseases, symptoms, treatments, and medications.
*   **Symptom Checker**: Search functionality to find diseases based on specific symptoms.
*   **AI Chatbot**: Conversational assistant to answer health-related queries (powered by Google Gemini).
*   **Doctor Finder**: Locate nearby healthcare providers (Coming Soon).
*   **Image Analysis**: Upload photos for visual condition analysis (Coming Soon).

## 🛠️ Technology Stack

*   **Frontend**: React, Vite, Tailwind CSS
*   **Backend**: Node.js, Express.js
*   **Data**: CSV-based data storage for lightweight performance
*   **API**: RESTful API structure

## 📦 Installation & Setup

### Prerequisites
*   Node.js (v14 or higher)
*   npm

### Backend Setup
1.  Navigate to the backend folder:
    ```bash
    cd backend
    ```
2.  Install dependencies:
    ```bash
    npm install
    ```
3.  Start the server:
    ```bash
    npm start
    ```
    *Server runs on `http://localhost:5000`*

### Frontend Setup
1.  Navigate to the frontend folder:
    ```bash
    cd frontend
    ```
2.  Install dependencies:
    ```bash
    npm install
    ```
3.  Start the accessible development server:
    ```bash
    npm run dev
    ```
    *App runs on `http://localhost:5173`*
